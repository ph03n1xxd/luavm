# LuaVM documentation

This directory contains the detailed LuaVM guides. Start with the guide that matches your task:

- [Getting started](getting-started.md): install LuaVM, prepare the host, and install Lua.
- [Command reference](commands.md): command syntax, selection, execution, and shell integration.
- [Configuration and storage](configuration.md): `.luavm.toml`, profiles, data roots, and precedence.
- [Development and releases](development.md): build, test, contribute, and package LuaVM.
- [Troubleshooting](troubleshooting.md): common installation and selection problems.
